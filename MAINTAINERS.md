# Maintainers

skillcheck is maintained in public. The current lead maintainer is [@mirawren](https://github.com/mirawren).

## Responsibilities

Maintainers are responsible for:

- reviewing changes for a concrete skill failure mode and false-positive risk;
- keeping the offline, deterministic runtime and its small dependency surface intact;
- responding to security reports under [SECURITY.md](SECURITY.md);
- keeping releases, compatibility claims, and generated references accurate; and
- helping contributors land substantive work without optimizing for activity counts.

The lead maintainer owns release credentials and the final release decision. The automated path and its verification steps are documented in [RELEASING.md](RELEASING.md).
Owner-only repository settings, including Pages, branch protection, topics, and the social preview,
are recorded in [docs/github-settings.md](docs/github-settings.md) so they can be audited instead of
living only in the GitHub UI.

## Becoming a maintainer

Maintainer access follows sustained, reviewable work: sound issue triage, careful fixes, respectful reviews, or stewardship of a language or subsystem. There is no commit or pull-request quota. A current maintainer nominates the contributor in a public issue, records the area of responsibility, and updates this file after agreement.

This policy is intentionally based on trust and substance. Trivial pull requests, split-up changes, automated activity, and metric padding do not build maintainership standing.
