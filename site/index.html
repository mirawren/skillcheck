The invisible bug

Nothing crashes when a skill is unreachable.

A description can be valid YAML, read beautifully, and still lose the one decision that matters: whether the agent loads it. Ordinary linters stop before that question.

Without skillcheck

“It didn’t do the thing.”

A vague bug report arrives after release, with no log line and no reproducible trigger decision.

With skillcheck

“These two descriptions are a coin flip.”

The pull request names the competing skills, the binding words, and the regression that introduced it.

Proof, not vibes

Every check answers a failure somebody can feel.

No prose grading. No model calls. No preference dressed up as policy.

Determinism is the product.

skillcheck reads Markdown and YAML as data. It does not execute instructions, open sockets, call a model, collect telemetry, or require credentials.
